# 🌍 Smart Traveler Planner

An all-in-one travel management web application designed to help users plan, organize, and manage their trips from a single platform.

## ✨ Features

- 🗺️ Trip Planner
- 📅 Itinerary Generator
- 💰 Budget Planner
- 🌤️ Weather Information
- 📍 Interactive Maps
- 🚶 Live Tracker
- 📄 Document Vault
- 🎒 Packing Assistant
- 🛡️ Safety Score
- 🤖 Travel AI Assistant
- 🏨 Booking Section
- 🚨 Emergency Contacts
- 👤 User Profile
- 💼 Travel Jobs & Applications

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- Leaflet.js

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- CORS

### APIs
- Open-Meteo Geocoding API
- Open-Meteo Weather API
- OpenStreetMap
